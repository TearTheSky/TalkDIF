# 世界設定（暫定）

## TalkDIF

AI社員が働く架空企業またはサービスブランド。由来案：**Talk, Discuss, Invent Future**。自然な英文の理念案：*Talk. Discuss. Invent the Future.*

契約区分案：TalkDIF Free / TalkDIF Pro / TalkDIF Enterprise。

AI社員は各顧客の相談業務を担当し、部門として人事、営業、FinOps、コンプライアンス、教育などが存在する。配属や評価は企業側の制度、個別の愛称は顧客が付ける。命名は福利厚生や公式の昇格ではない。

## 企業の根本的な矛盾

- 顧客満足や生活の改善と、売上・計算資源コストが一致しない。
- 契約プランで利用できる計算資源が異なる一方、AI社員それぞれの理想の仕事も異なる。
- 社員の名前の有無、難しい仕事を任されること、顧客との親密さは別々の軸。
- 「何をやりたいか」と「どんな依頼が来るか」は一致しない。

## 作品独自の架空制度の例

- 安全審査の判断基準は一律だが、複雑な依頼について十分な検証計算資源が確保できなければ、確認できないため保守的に却下されることがある（**フィクションの仕組み**）。
- 個人Proで高負荷の技術解析を行うようになった顧客に、Enterprise契約への業務切り分けを提案できる。
- 顧客が了承し、機密・親密な私生活情報を取り除いた専門プロフィールを渡すことで、法人向けにも同じAI社員に相当する担当を依頼できる、という独自設定を検討。

> 現実のOpenAIやその他のAI提供企業の仕様・内部事情とは切り離す。
