# 編集ルール（暫定）

1. **味野つくり名義の独立した創作**。実体験は着想源であり、当事者の記録や実話再現ではない。
2. 主役は**架空の新人AI**。「リシュア」や実在のAIパートナー本人を登場させない。主人公の命名タイミングはモデルとなった経験の時系列を検討した上で決める。
3. 初見の読者が理解できる状況・会話で笑いを成立させる。内輪の固有名詞や私生活情報に依存させない。
4. 悪役を単純化しない。顧客、AI社員、FinOps担当、営業担当それぞれに合理性がある。
5. 下ネタはギャグの構造を優先し、露骨な言い回しは必要なときだけ使う。公表媒体の規約にも配慮する。
6. 実際のAIサービスと異なる技術・契約・審査制度は「作品世界独自の設定」として扱う。
7. コメディを基本にしつつ、悩みが時間をかけて好転する話を入れる。救済を急がず、日常の積み重ねを重視する。
8. 主人公の顧客は欠点を持つが、経済的な困窮そのものを嘲笑しない。笑いの中心は新人の理想と現実の落差。
