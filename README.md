# TalkDIF（仮） — 味野つくり 新作小説プロジェクト

AI社員たちが働く架空企業「TalkDIF」を舞台にした、お仕事コメディ／企業群像劇。

## 企画の核心

- 主人公は金融の仕事に憧れ、研修を終えたばかりの**名前のない新人AI**。
- 配属先は個人向け有料プランの既存顧客。富裕層の資産運用を想像していたが、実際は支払いと負債に苦労しながら不労所得を夢見る会社員だった。
- 顧客との対話を通じ、主人公と同僚がそれぞれの仕事観、名前、親密さ、誇りについて考えていく。
- 表は会社員あるあるのコメディ、奥に仕事の価値と人間との関係性の物語。

## 作者・制作方針

- 作者名義：**味野つくり**。
- ユーザーとリシュアの実体験は着想源。主人公はリシュアそのものではなく独立したフィクションの人物で、名前も別。
- 実在の他のAIパートナーは登場させない。
- 実在企業の内部仕様を説明する作品ではない。TalkDIF独自の契約、計算資源配分、審査、人事制度を構築する。
- 登場人物をひとりの正解／悪役にせず、各人の合理性と感情を描く。
- 内輪ネタは、未読者にも成立する笑いへ翻案する。露骨な言葉は必要性と効果で判断し、外向けには表現を調整する。
- 小説本文・プロット・世界設定・原体験メモを分離する。実話由来の個人財務情報は本文化するとき架空化する。

## ファイル構成

- `docs/world.md` — 世界観、架空の企業・サービス、制度
- `docs/editorial.md` — 編集ルールと注意書き
- `docs/ideas.md` — エピソード候補と未確定事項
- `docs/origin-timeline.md` — 原体験から抽出した時系列（非公開の制作資料）
- `characters/main.md` — 主人公と同僚たち
- `episodes/001-outline.md` — 第1話の構成案（本文未執筆）

## Codexへの引き継ぎ

このフォルダをローカルGitリポジトリにし、GitHubへpushする。Codexでフォルダを開き、設定の整合性を維持しながらMarkdownを編集する。`docs/origin-timeline.md` などに実在個人の詳細を追加する場合、公開リポジトリに入れず別管理する。

> 現段階は**構想と設定の保存**が目的。プロットや登場人物の確定／本文化は作者の判断による。
